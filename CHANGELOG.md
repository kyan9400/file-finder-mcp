# Changelog

## [1.0.0] - 2026-08-26

### Added

- Packaged MCP server and standalone JSON CLI.
- Typed structured results, extension filters, exclusion globs, and result limits.
- Deterministic relevance ranking and scan telemetry.
- Cross-platform tests, CI, build verification, and release automation.

### Security

- Fixed workspace boundary configured only at process startup.
- No directory-symlink traversal.
- Protected dependency, VCS, cache, and build-directory exclusions.
- Hard cap on scanned files and returned results.
